# Pin

PostgreSQL-native, Rust-first full-text search.

## Current scope: G0

This is a host-boundary prototype, not a searchable index. G0 establishes exact
build inputs, guarded PostgreSQL callbacks, ABI checks, lifecycle tests, and
executable design models. It does not implement storage, SQL match semantics,
ranking, visibility shortcuts, or SIMD. No performance results are claimed.

Validation target: PostgreSQL 18.6, Rust 1.98.1, pgrx/cargo-pgrx/pgrx-pg-sys 0.19.2,
x86-64 Linux, UTF-8 databases, 8 KiB pages. This is a selected target, not yet a
passing compatibility claim. G0 stays open until the clean-server checks pass
and the unsafe boundaries receive independent review.

The development VM does not install Rust. Compilation and PostgreSQL execution
run in GitHub Actions. The initial dependency lock is generated by Cargo there;
no hand-written or invented lockfile is accepted.
